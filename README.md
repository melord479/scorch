# SCORCH — дисторшн для баса / 808 (VST3 для FL Studio)

Минималистичный плагин для тяжёлого «рэйдж»-перегруза 808: сабы остаются чистыми и тяжёлыми,
а середина и верх получают агрессивные гармоники (стиль Osamason / Ken Carson / Opium-звук).

## Как получить готовый .vst3

### Вариант 1 — без установки чего-либо (GitHub Actions)
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки
   (кнопка *Add file → Upload files*, перетащите всё, включая папку `.github`).
2. Откройте вкладку **Actions** — сборка запустится сама (≈5–8 минут).
3. Откройте завершённый запуск → внизу **Artifacts → Scorch-VST3-Windows** → скачайте zip.
4. Внутри папка `Scorch.vst3` — это и есть плагин.

### Вариант 2 — локально на Windows
Нужны Visual Studio 2022 (workload «Desktop development with C++») и CMake.
```
cmake -B build -A x64
cmake --build build --config Release --target Scorch_VST3
```
Результат: `build/Scorch_artefacts/Release/VST3/Scorch.vst3`
(Для проверки без DAW можно собрать цель `Scorch_Standalone`.)

## Установка в FL Studio
1. Скопируйте папку `Scorch.vst3` в `C:\Program Files\Common Files\VST3`.
2. FL Studio → *Options → Manage plugins* → **Find installed plugins** (убедитесь, что папка VST3 в списке путей).
3. Плагин появится в *Add → More plugins* → Scorch (или в Plugin database → Installed → Effects → VST3).
4. Ставьте на 808-канал (или на микшерную вставку) после тюнинга баса.

## Управление
| Блок | Параметр | Что делает |
|---|---|---|
| Центр | **Drive** 0–48 дБ | Сила перегруза |
| | **Bias** | Асимметрия: чётные гармоники, «хрип» |
| Слева | **Mode** | TUBE (тёплый), FUZZ (диод, асимметричный), FOLD (вейвфолдер), HARD (жёсткий клип), RAGE (комбо fuzz+fold) |
| | **Low: Stereo/Mono** | Нижняя полоса в моно (рекомендуется) |
| Shape | **Fold** | Дополнительный вейвфолдер после дисторшна |
| | **Crush** | Снижение разрядности (16 → 3 бит) |
| | **Decimate** | Снижение частоты дискретизации |
| Low end | **Punch** | Подъём/срез 90 Гц *до* дисторшна (сколько баса идёт в перегруз) |
| | **Split** | Частота разделения чистого саба и дисторшна (40–300 Гц) |
| | **Sub** | Сколько чистого саба оставить вместо перегруженного низа |
| Tone | **Low Cut / High Cut** | Фильтры после дисторшна |
| | **Ceiling** | Мягкий потолок: плоские «верхушки» = громкость и плотность |
| Output | **Width** | Стерео-ширина перегруженной середины/верха (бас остаётся в моно) |
| | **Mix / Output** | Dry/Wet и выходной уровень |
| Верх справа | **Oversampling** | Off / 2x / 4x — меньше алиасинга (добавляет латентность, плагин её сообщает хосту) |

Слева на экране — живая кривая передачи (как сигнал «гнётся»), внизу — измеритель выхода.
Двойной клик по ручке — сброс. В центре сверху — 10 пресетов (Rage 808, Opium Grit, Carson Crush, Hyper Fold, Wall Of Bass и др.).

## Идея сигнальной цепи
`Punch → Drive/Bias → Mode → Fold → Crush/Decimate → Ceiling → [разделение на Split: чистый саб + перегруженный верх] → Width / Low‑High Cut → Ceiling → Mix → Output`
Всё нелинейное работает в оверсэмплинге; полосы разделяет кроссовер Linkwitz–Riley 24 дБ/окт.

## Что проверено, а что нет
Проверено тестами ядра (`tests/dsp_test.cpp`, g++, проходят все проверки):
латентность оверсэмплера и выравнивание dry-пути, плоская сумма кроссовера (±0.03 дБ),
стабильность на шуме при экстремальных настройках, снижение алиасинга (−13.6 → −20.9 → −25.2 дБ для Off/2x/4x),
потолок и отсутствие DC на всех пресетах.
```
g++ -O2 -std=c++17 tests/dsp_test.cpp -o dsp_test && ./dsp_test
./dsp_test --demo demo_808.wav      # рендер демо: чистый 808 и 5 пресетов
```
**Не проверено:** сама JUCE-обвязка и интерфейс не компилировались в среде, где писался код (там нет JUCE и Windows-компилятора).
Если сборка выдаст ошибку — пришлите текст ошибки из лога, поправлю.

## Лицензия JUCE
Проект использует фреймворк JUCE (AGPLv3 / коммерческая или персональная лицензия JUCE).
Для личного использования это не проблема; при распространении плагина проверьте условия лицензии JUCE.
